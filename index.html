Saiz Halaman Custom

Cara Penggunaan:

  • Pen (P): Lukis/menulis dengan pen
  • Teks (T): Klik dan taip, Enter untuk selesai
  • Bentuk (B): Pilih jenis bentuk, klik dan tarik untuk lukis. Sesuai untuk peta minda!
  • Jadual (J): Buat jadual. Shift+Klik atau Ctrl+Klik untuk pilih beberapa sel, kemudian Gabung.
  • Pemadam (E): Padam lukisan
  • Gambar (G): Import gambar, klik untuk pilih, tarik untuk gerak, tarik bucu untuk resize, klik ✕ untuk padam
  • Template: Tukar jenis garisan (biasa/4 suku/petak/kosong)
  • Timer: Set masa dan tekan Mula untuk pemasa undur
  • Skrin Penuh (F): Mod persembahan tanpa toolbar
  • Tarik bucu: Tarik titik biru (teks) / hijau (bentuk) / merah jambu (gambar) untuk resize
  • Auto-simpan: Data disimpan automatik setiap 30 saat
